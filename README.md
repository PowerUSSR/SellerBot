# SellerBot

NPC-бот "продавец" для Paper/Spigot 1.20 на сервере **VortexiaPolit** — продаёт игрокам предметы за игровую валюту, с автоматической ротацией страниц товаров.

## Команда

`/sellerbot <spawn|skin|page|rotate|info>` — право `sellerbot.admin` (по умолчанию только ОП).

## Зависимости

- **Vault** (обязательно)
- **ProtocolLib** (обязательно)

## Сборка

```
build.bat
```
